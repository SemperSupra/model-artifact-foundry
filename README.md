# Model Artifact Foundry

Public execution and distribution plane for curated, versioned third-party ML models, checkpoints, and other large replaceable artifacts.

This repository is intentionally public and independently operable. It will contain generic source declarations, schemas, public-safe validators, provenance/evidence, OCI artifact publication mechanics, approved catalog metadata, and digest-pinned hydration tooling.
