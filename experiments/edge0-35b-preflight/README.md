# Edge0 35B exact upstream source metadata preflight (NO model bytes)

Research-only admission candidate for Model Artifact Foundry: fetch and inspect metadata for the *exact* Edge0 35B source revision pinned in upstream Edge0's `edge0-infer/tools/assets/edge0_35b/source.lock.json` at Git SHA `f6bfa5546bcf89919f86946ec669bcc7f4cd526d`. Model reference `Edge0/Edge0-35B-A3B-preview@e21098e7faa916a00f5493795f12f20497d032bb`.

Perform one bounded, public, unauthenticated JSON API call to Hugging Face (max 3 MB, timeout 25 s) requesting blob metadata. Require exact repository, model revision, publicly accessible and non-gated status, license metadata `apache-2.0`, full inventory of **eleven** locked original files, and SHA-256 equality between upstream lock and independent HF LFS metadata for four base safetensors shards + LoRA and prerouter. Record file sizes, whether each fits under a conservative 9 GB per-layer planning bound, and which small non-LFS files still lack independently verified SHA-256. Offline unit tests exercise negative cases. No authenticated fetch, downloader API, model input, registry write or real weights.

**Evidence class:** provider metadata plus independent upstream source lock, not downloaded-byte SHA; LFS SHA only proves provider-declared object digests agree with source. Small non-LFS config/template files remain `metadata_only` until separately downloaded and independently hashed. Neither an Apache-2.0 model card nor exact hash metadata proves derivative rights, provenance review, conversion equivalence, native runtime quality, or authorization to republish.

**MAF boundary:** current approved Foundry `tools/hydrate.py` expects one `model.tar.gz`, whose ~20 GB-sized full-model payload would exceed typical OCI per-layer bounds. Upstream safetensors already have four 4.4–5.37 GB shards and might fit if packaged as individual OCI layers, but that requires a new reviewed bundle schema and hydration adapter, not pretending the old manifest accepts it. Existing synthetic OCI-layer prototype PR #88 qualifies a primitive only.

**Authority:** MAF-private issue #6 rights/acquisition/mirror and #7 selection; public Foundry AGENTS.md retains publication authorization. BrowserParity-private #25 retains runtime use decisions. Workload is standard public free hosted GitHub Actions. Strictly non-promoting: no GHCR push, new approval, full model inference, or production effects.
